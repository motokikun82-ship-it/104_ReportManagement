# 業務日報管理アプリ (ReportManagement)

## 🎯 目的・特徴
本アプリケーションは、日々の業務内容（項目と件数）を素早く記録し、SQLiteを用いて軽量かつ高速に永続化するためのWindowsデスクトップアプリです。
「日報の件数を入力するだけで自動保存される」「引き算方式のToDoリスト」という現場の要望に特化したUIを提供します。

### 主な特徴
- **超高速起動**: C# WPF (.NET 8) ネイティブアプリ。
- **リアルタイム自動保存**: 件数の増減やテキスト入力のたびに即座にデータベースへ保存されます。
- **引き算方式ToDo**: チェックを入れたら完了（必要に応じて削除）するだけのシンプルな残タスク管理機能。
- **ダークテーマ対応**: 目に優しいダークテーマを標準採用。
- **カレンダーマーカー機能**: 日報が入力された日にはカレンダーに青い「●」マーカーが付き、実績が一目で分かります。

---

## 🚀 起動方法の簡易手順

1. **前提条件**:
   - Windows 10/11
   - .NET 8 デスクトップランタイムがインストールされていること。
2. **ビルド**:
   ```bash
   dotnet build --configuration Release
   ```
3. **実行**:
   - `bin/Release/net8.0-windows/ReportManagement.exe` をダブルクリックして起動します。
   - 起動時、同じフォルダに `report.db` (SQLiteデータベース) が自動的に生成されます。

## 📖 詳細な使用方法

### 1. カレンダーと日付操作
- 画面右上のカレンダーで日付をクリックすると、その日の日報およびToDoに切り替わります。
- 画面上部の「◀」「▶」「今日」ボタンを使って前後の日に移動できます。
- 日報の入力がある日はカレンダーの日付の下に青い点が付きます。

### 2. 日報エントリーの操作
- **テンプレートから追加**: 毎日決まった項目（「商品登録」「受注処理」など）がある場合、「＋ テンプレから追加」を押すことで一括展開されます。（デフォルト設定のテンプレートは、起動時に今日の日報が空であれば自動展開されます）
- **自由追加**: 件数管理が必要な単発のタスクを追加します。
- **突発メモ追加**: 件数の概念がないメモ書き用の行を追加します。
- **件数変更**: ➖ ➕ ボタンを押すか、数値を直接書き換えます。（即時保存されます）

### 3. ToDoリストの操作
- 右下の「今日のToDo」で、その日にやるべきタスクを追加します。
- チェックを入れるとグレーアウトして取り消し線が引かれます。（チェック状態も即時保存されます）
- **未完了タスクの引き継ぎ**: 翌日にアプリを起動した際、前日の「未完了」のToDoタスクは、当日のToDoに自動的にコピー（引き継ぎ）されます。

### 4. 検索機能
- 画面左上の検索ボックスにキーワードを入れて🔍ボタンを押すと、過去の日報から合致する項目やメモを横断検索します。
- 検索結果の行をクリックすると、その日の日報画面へ一瞬でジャンプします。

### 5. テンプレート管理
- 画面右上の「テンプレート管理 ⚙️」から、業務グループとそれに紐づくデフォルト項目を自由にカスタマイズできます。

---

## ⚠️ 注意点
- **データベースファイルの取り扱い**:
  データはすべて実行ファイルと同じフォルダの `report.db` に保存されます。バックアップを取る際や別のPCに移行する際は、この `report.db` ファイルをコピーしてください。
- **削除操作**:
  ゴミ箱アイコン（🗑）を押すと即座にデータが削除されます。削除の取り消し（Undo）はできないためご注意ください。
