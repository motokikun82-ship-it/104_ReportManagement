# 業務日報管理アプリ (ReportManagement)

## 🎯 目的・特徴
本アプリケーションは、日々の業務内容（項目と件数・メモ）を素早く記録し、SQLiteを用いて軽量かつ高速に永続化・集計するためのWindowsデスクトップアプリです。
日報入力だけでなく、自動引き継ぎToDo、スケジュールテンプレート、業務メモ、視覚的な集計グラフ（LiveCharts2）までを1画面または連動ウィンドウで軽快に操作できます。

### 主な特徴
- **超高速起動**: C# WPF (.NET 8) ネイティブ実装。
- **リアルタイム自動保存**: 入力・変更のたびに即座にデータベースへ保存され、保存忘れの心配がありません。
- **引き算方式ToDo**: 未完了タスクの翌日自動引き継ぎ、時間帯・詳細メモの折りたたみ展開に対応。
- **視覚的集計レポート**: 日別・週別・月別・年別の推移を折れ線/積み上げ棒グラフで可視化。全項目／グループ別の絞り込みやCSV出力に対応。
- **多彩なテーマ機能**: 視認性に優れたダークテーマ（Standard, Classic, Ocean, Sunset）およびライトテーマを自由に切替可能。
- **情報の一元化カレンダー**: 日報、未完了ToDo、メモの有無をカラーマーカーで一目で識別可能。

---

## 🚀 起動方法の簡易手順

1. **前提条件**:
   - Windows 10 / 11
   - .NET 8 デスクトップランタイム
2. **ビルド**:
   ```bash
   dotnet build ReportManagement.csproj --configuration Release
   ```
3. **実行**:
   - `bin/Release/net8.0-windows/ReportManagement.exe` を実行します。
   - 実行ファイルと同じディレクトリに `report.db` (SQLiteデータベース) が自動生成・管理されます。

## 📖 詳細な使用方法

### 1. カレンダーと日付操作
- **日付選択**: カレンダーの日付をクリックすると、その日の日報・ToDoへ切り替わります。
- **マーカー表示**:
  - 🔵 青丸: 日報（件数または突発メモ）が入力されている日
  - 🔴 赤丸: 未完了のToDoタスクが残っている日
  - 🟠 オレンジ丸: 日付に紐づくメモが存在する日
- **「今日」「◀」「▶」**: 素早く今日や前後の日付に移動できます。

### 2. 日報エントリーの操作
- **＋ テンプレから追加**: 登録済みのテンプレートグループを選んで一括展開します。
- **＋ 自由追加**: 件数管理（➖ / ➕）が可能な項目を個別に追加します。
- **📝 突発メモ追加**: 件数を持たないテキストメモ行を追加します（内容を複数行で展開・記入可能）。
- **⭐ よく使う**: 登録しておいた頻出項目一覧からワンクリックで追加できます。
- **実行チェック**: チェックが必要な項目にはチェックボックスが表示され、完了すると項目名がグレーアウトします。
- **並び順変更**: 各行の「↑」「↓」ボタンで項目の並び順を調整できます。

### 3. ToDoリスト (残タスク管理)
- **タスク追加**: タスク名を入力してEnterまたは「追加」ボタンで登録。任意で開始/終了時刻や詳細メモも同時に設定可能。
- **詳細展開**: 各ToDoの「▼」アイコンをクリックすると、時刻指定や長文メモをインラインで閲覧・編集できます。
- **自動引き継ぎ**: 完了チェックを入れていないToDoは、翌日以降に起動した際に自動的に引き継がれます。
- **インクリメンタル検索**: 上部のToDo検索ボックスから過去・現在のタスクを瞬時にフィルタリングできます。

### 4. 📊 集計レポート機能
メイン画面右上の「📊 集計」ボタンから起動します。
- **期間モード**: 「月別（1〜12月）」「年別（複数年比較）」「カスタム期間（開始日〜終了日）」から選択可能。
- **表示単位**: 「日」「週」「月」「年」単位で集計軸を切り替え可能。
- **項目フィルタ**:
  - **全項目を選択 / 全項目を解除**: グループに関係なく、全項目の表示・非表示を一括で切り替えます。
  - **グループ内全選択 / グループ内全解除**: 現在選択しているタブ内の項目のみを一括で切り替えます。
  - チェック状態は次回起動時にも記憶されます。
- **グラフ＆クロス集計表**:
  - 折れ線グラフ／積み上げ棒グラフのリアルタイム描画。
  - 期間ごとの合計および平均値が算出された表が表示されます。
- **CSVエクスポート**: 表示中の集計表をCSVファイルとして保存できます。

### 5. メモ・テンプレート・各種設定
- **📝 メモ**: 日付指定メモおよびピン留め可能な全般メモを管理。
- **テンプレート管理 ⚙️**: 日常業務のグループおよびデフォルト項目の作成・編集。
- **スケジュールテンプレート**: 「毎月第2火曜日」「毎週月曜日」など、特定周期で自動挿入する定期業務を設定。
- **設定 ⚙**: テーマカラー（Dark, Ocean Dark, Sunset Dark, Classic Dark, Light）や祝日同期の設定。

## ⚠️ 注意点
- **データのバックアップ**:
  データはすべてアプリケーションと同じフォルダの `report.db` に格納されています。バックアップや環境移行時は `report.db` をコピーしてください。
- **削除操作**:
  ゴミ箱アイコン（🗑）や「一括削除」による削除は即座に反映され、元に戻せません。
