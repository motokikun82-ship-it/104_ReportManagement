# 修正内容の確認 (Walkthrough): 集計画面の全項目選択機能の追加およびドキュメント最新化

集計画面（`AggregationWindow`）における全選択/全解除ボタンの改修および、プロジェクトドキュメント（`SPECIFICATION.md`, `README.md`）の最新化を実施しました。

---

## 🛠 実施した主な変更

### 1. 集計画面の全項目選択／グループ内選択機能の実装
- **ViewModelの拡張 (`AggregationViewModel.cs`)**:
  - `SelectAllItemsCommand` および `DeselectAllItemsCommand` を新設。
  - すべてのグループ（未分類グループを含む）の全アイテムに対して `IsChecked` を一括で `true` / `false` に切り替え、集計表・グラフを即時再描画するように実装。
- **Viewの改修 (`AggregationWindow.xaml`)**:
  - ご要望（パターンB）に基づき、以下の4つのボタンを配置：
    - 「**全項目を選択**」「**全項目を解除**」: グループに関係なく、全アイテムを対象に一括切替
    - 「**グループ内全選択**」「**グループ内全解除**」: 現在選択中のグループタブ内のアイテムのみを対象に切替

### 2. ドキュメントの最新化
- **仕様書 (`docs/SPECIFICATION.md`)**:
  - アプリに追加されている全機能（集計・グラフ、お気に入り項目、祝日設定、メモ帳機能、スケジュールテンプレ、テーマ設定）を網羅。
  - 画面構成、最新のSQLiteデータベース設計（全テーブル・カラム）、条件分岐仕様を最新情報に更新。
- **取扱説明書 (`docs/README.md`)**:
  - アプリの起動手順、各画面（カレンダー、日報、ToDo、集計レポート、メモ、各種設定）の最新操作方法・注意点を整理して記載。
